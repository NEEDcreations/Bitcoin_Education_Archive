⚡ Peers, Partnerships & Gifting
October 13, 2026 · v2082
Previous
🟠 Big Update
The Peer & Partnership System is live.
Bitcoin Quest is no longer just a solo journey. Connect with other learners, send each other gifts, and build lasting partnerships that level up the more you interact. Think Pokémon Go friendship levels — but Bitcoin-native.
👉 Add your friends as peers inside the app!
🤝 Partnership Levels — New Feature
FEAT
6 Bitcoin-themed partnership levels. As you and a peer exchange gifts, your partnership grows. Each level has a Lightning Network-inspired name and unlocks a big XP bonus for both of you:

⬜ Unconfirmed — just connected
🟨 Opening Channel — 1 gift exchanged · +3,000 XP each
⚡ Routing Nodes — 21 gifts · +21,000 XP each
⚙️ Adjusted Fees — 44 gifts · +44,000 XP each
🔗 Balanced Liquidity — 144 gifts · +50,000 XP each
🟠 Wumbo Channel — 210 gifts · +100,000 XP each
FEAT
Live level-up popup. The moment you and a peer reach a new level, both of you get a full-screen celebration card — with the level name, your partner's username, a flavour description, the XP reward, and a progress indicator across all 6 levels. Auto-dismisses after 12 seconds.
FEAT
Peer level badge in notifications. Partnership level-ups appear in your notification feed with a ⚡ icon so you can catch up if you missed the popup.
SEC
All partnership data — levels, XP awards, gift counts — is written exclusively by server-side Cloud Functions. Clients can read their own partnership data but can never write it. Fully protected against replay and self-award attacks.
🎁 Peer-to-Peer Gifting
FEAT
Send gifts to your peers. Earn gift boxes from daily spins and streaks, then send them to any peer. They open the gift and reveal Orange Tickets inside. Sending a gift earns the sender +25 XP instantly.
FEAT
One-pending-per-pair rule. You can only have one open gift waiting for a given peer at a time. They need to open it before you can send another — keeps things intentional.
FEAT
Gift notification with a tap-to-open button delivered directly to the recipient.
SEC
Gift opens are rate-limited to 21/day. Ticket counts are stored server-side and revealed only at open time — the client never knows the value before opening.
🔐 Two-Factor Authentication — Safari Fixes
FIX
Phone 2FA now works on Safari & iOS. Apple's ITP (Intelligent Tracking Prevention) was silently blocking the reCAPTCHA iframe used for SMS verification. Fixed with multiple targeted patches: same-origin authDomain proxy, visible reCAPTCHA on tap, and App Check disabled to eliminate Enterprise 401 errors. All sign-in methods now complete 2FA on Safari without hanging.
FIX
Double 2FA overlay prevented — a race condition caused the SMS challenge modal to appear twice on some mobile redirects. Guard added so it only fires once.
FIX
After 2FA success, the sign-in modal now closes and the user lands on home instead of seeing a stale form.
🔑 Sign-In — New Recovery Flow
FEAT
"Trouble signing in?" link added to sign-in screen. Can't find your link? Tap it, enter your email, get a fresh one. No password needed — never was. The Bitcoin-native answer to "forgot password."
FEAT
Sign-in button copy updated from "Send Magic Link" → "Send Sign-In Link" for clarity. Supporting text updated throughout to make the passwordless flow obvious to new users.

Two-Factor Authentication & Raid Intelligence
October 4, 2026 · v2080
Previous
🔐 Security
FEAT
Phone 2FA is live. Users can now enroll a phone number under Settings → Security. Firebase sends a real SMS verification code — enter it to enable two-factor auth on your account. Supported on all sign-in methods (email, Google, Twitter, GitHub, Facebook). Accounts with phone 2FA get a challenge prompt automatically on every sign-in.
FEAT
Authenticator app 2FA is live. Scan the QR code in Settings → Security with Google Authenticator, Authy, or any TOTP app. Disable any time by entering your current 6-digit code. TOTP is fully server-side — secrets never leave Firebase Cloud Functions.
FIX
TOTP Cloud Functions were deployed as 2nd Gen, which the Firebase compat SDK (v9) doesn't pass auth tokens to — every call returned functions/unauthenticated. Redeployed as 1st Gen. Also fixed a key mismatch where the frontend expected result.data.qrUrl but the function returned result.data.qr.
⚔️ Raid Boss
FEAT
Damage rate displayed on boss card. Every boss now shows exactly how much damage your actions deal — e.g. "⚔️ 1 quiz completed = 5 dmg" — so you always know the most effective way to contribute.
FEAT
Boss preloader. The active raid boss is now silently loaded on sign-in, before you ever open the Raid tab. Previously, poll voters and other users who never visited the Raid tab had their contributions silently dropped. Fixed.
FEAT
More damage metrics. Bosses can now use any of 16 action types to deal damage: quiz completions, flashcard sets, Timechain TV watch time, Bitcoin Beats listen time, poll votes, forum posts, trivia correct answers, topic reads, new topics visited, badges earned, 7-day streaks, Lightning tips sent, chat messages, and total XP earned.
FIX
XP-based bosses now accumulate damage in a 100 XP buffer before firing a contribution call. Prevents fractional damage values and reduces Firestore writes during rapid XP gains.
🔧 Dashboard Fixes
FIX
Lightning Network capacity showed NaN — caused by calling fmtNum() on a value already converted to a formatted string. Fixed the calculation chain; capacity now shows correctly (e.g. "5,342 BTC").
FIX
Dashboard cache bumped to v2 — clears stale null values that were persisting from a prior bad fetch and showing blank tiles on return visits.
FIX
Indicator count corrected to 32 — the count previously excluded indicators with no flash logic, making the displayed total inconsistent.
Bitcoin Dashboard Overhaul
October 2, 2026 · v2079
Previous
🆕 New
FEAT
Live candlestick chart — 5-minute OHLCV, 20 bars, on the Bitcoin Network dashboard. Last candle updates every second with live trade price.
FEAT
Real-time price WebSocket — Coinbase Exchange aggTrade stream fires on every individual trade (multiple times/second). Price tile, candle, and 24h High/Low all update live.
⚡ Performance
PERF
Dashboard API proxied through Cloudflare Worker. 1,000 users opening the dashboard simultaneously = 1 upstream API call, not 1,000. All data (price, hashrate, fees, mempool, candles) fetched server-side and edge-cached for 90 seconds. Rate limiting from CoinGecko, Binance, and other external APIs is eliminated entirely.
🔧 Fixes
FIX
Dashboard crashed on second open — halvingEta was stored as a Date object but JSON-serialized to a string in localStorage. Calling .toLocaleDateString() on a string threw, breaking the entire render for returning users.
FIX
Supply, Market Cap, ATH, and ATH drawdown no longer show — — CoinGecko rate-limits Cloudflare IPs. Supply now computed directly from block height (exact formula). Market cap derived from price × supply. ATH uses a hardcoded fallback (08,135, Jan 2025) if CoinGecko fails.
FIX
4 Top Indicators (Fear & Greed, ATH Drawdown, NVT Ratio, BTC Dominance) were silently skipped when their data wasn't available on first load — all now always render with "Loading..." placeholders. Indicator count is stable at 31.
FIX
Candlestick chart axis labels increased to 12px — previous sizes (8.5px Y-axis, 7.5px X-axis) were unreadable on most screens.
FIX
Timechain Calendar iframe restored — timechaincalendar.com was dropped from frame-src when the SEO router CSP was rewritten.
🧠 Quest Hub
FIX
Trivia vote totals update immediately after answering. Previously showed "1 answer today" (just your own vote) until you switched tabs and came back. Now chains a real Firestore read after the write and patches the DOM directly.
FIX
Poll vote results show correct community counts instantly after voting. Was using get({ source: 'server' }) which raced against the just-committed transaction. Removed the server-source override — Firestore's local cache already had the committed data.
